# Product Search & Filter

A simple e-commerce product grid with a live search filter and shopping cart.

## Features
- Live product search — filters product cards in real time as you type, no page reload needed
- Add-to-cart functionality with a running cart total
- "No products found" message when a search returns no matches
- Built with vanilla HTML, CSS, and JavaScript — no frameworks or libraries
